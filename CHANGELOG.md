# Changelog

All notable changes to this project will be documented in this file.

## [1.1.0] - 2026-04-22

### Added
- **High-IQ reasoning enhancements**: 8 new MCP tools for advanced cognition
- `visualize_thought_graph`: Generate SVG/ASCII visualizations of thought graphs
- `simulate_devils_advocate`: Auto-generate counterarguments and opposing viewpoints
- `cross_disciplinary_synthesis`: Combine insights from multiple domains
- `temporal_projection`: Project thoughts into future/past scenarios
- `ethical_framework_evaluation`: Evaluate through deontological, consequentialist, virtue, rights-based ethics
- `emotional_intelligence_analysis`: Analyze emotional tone, empathy, persuasion effectiveness
- `explain_decision`: Generate human-understandable decision explanations with counterfactuals
- `social_impact_analysis`: Analyze stakeholder emotions, group cohesion, social impact
- **Enhanced ThoughtNode types** with language, emotional tone, uncertainty models, ethical considerations
- **Cross-domain reference system** for analogical reasoning
- **Social impact modeling** with stakeholder emotion mapping
- **Uncertainty quantification** with confidence intervals and sensitivity analysis
- **Multi-language support** (en, tr, de, fr, es, jp, zh, ru)
- **Meta-cognitive layers** (Level 1-5) for recursive reasoning
- **Updated npm keywords** with ethics, emotional-intelligence, cross-disciplinary, temporal-reasoning
- **All 118 unit tests pass** with new enhancements
